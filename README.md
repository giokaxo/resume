## Source

The LaTeX source lives in [Overleaf](https://www.overleaf.com/project/6af05fb2dc9b2950190cd6c7). A snapshot of the project is kept in `Resume - Giorgi Kakhoshvili.zip`.

If changes are needed, edit the Overleaf project, not the zip. Then re-download the project and export the PDFs (`Backend.pdf`, `Frontend.pdf`, `Full-stack.pdf`) into this repo.

The zip contains:

- `main.tex`, `resume-backend.tex`, `resume-frontend.tex`: entry points for the general (full-stack), backend and frontend versions. In Overleaf, switch between them with Menu > Main document.
- `preamble.tex`, `body.tex`: shared setup and layout
- `sections/`: individual resume sections
